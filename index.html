02 / Recovery and validated publication

NYC Taxi Data Platform

Local / Docker / CI

Bad monthly files and failed transformations can corrupt downstream reports. Built a Dagster/dbt/DuckDB pipeline with auditable quarantine, source fingerprints and a validated candidate release. Eight consumer tables and their version metadata publish in one transaction; failure-injection tests preserve the previous valid version. Runs locally, in Docker and in CI on public TLC data; the recorded full-data reconciliation predates the current publisher.

HN Pulse

Small operated public data product

A scheduled dashboard is only useful while its data remains complete and fresh. Built a Python/dbt pipeline that snapshots the Hacker News API, enforces six model contracts and gates publication with 27 data tests. Failed runs preserve the last complete export; the browser and a separate workflow check freshness. Operated as a small public data product on GitHub Actions and Pages.
